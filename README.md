# React Journey

A dedicated repository tracking my hands-on progress, experiments, and mini-projects as I continue learning modern React.js.

This project includes practical examples covering core React concepts such as:
- JSX and component structure
- Props and data passing
- State management with useState
- Conditional rendering and filtering
- Side effects with useEffect
- Refs with useRef
- Reducers with useReducer

---

## Project Overview

This repository is structured as a daily learning path, where each folder represents a React concept or exercise. The goal is to build small but meaningful projects to strengthen understanding of React fundamentals in a practical way.
